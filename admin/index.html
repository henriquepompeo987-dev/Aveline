Configure o Supabase

O painel precisa da URL e da chave pública (anon) do projeto aveline no Supabase.

  1. Abra assets/js/config.js.
  2. Preencha SUPABASE_URL e SUPABASE_ANON_KEY (Supabase › Project Settings › API).
  3. Rode supabase/schema.sql e supabase/seed.sql no SQL Editor.
  4. Ative o provedor GitHub em Authentication › Providers.

Passo a passo completo no README.md.
